Space Shooter.

A high-refresh rate 2D retro arcade shooter built entirely with vanilla JavaScript and the HTML5 Canvas API, featuring custom collision detection and particle physics.

Gameplay Preview

Custom 2D canvas engine with enemy wave generation and particle effects.

Project overview

Space Shooter was engineered to understand game loops and low-level 2D graphics rendering without external game engines. It runs on a fixed-timestep `requestAnimationFrame` loop that updates velocities, evaluates bounding-circle collisions, and renders projectiles in real time.

Featuring progressive difficulty curves, procedural starfield parallax, audio synthesizers via Web Audio, and dynamic particle explosions when targets are destroyed.

Key technical highlights

  • Zero dependency vanilla JavaScript engine optimized for steady 60 FPS performance.
  • Multi-layered parallax starfields with variable radial particle velocity.
  • Bounding-radius collision detection between lasers, shields, and incoming obstacles.
  • Local storage integration for persistent high score tracking across sessions.
