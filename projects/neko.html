Neko.

An anime companion web app for discovering titles, searching the catalog, and building a watchlist with anime data from AniList.

Gallery

A few screens from the Neko app.

Project overview

Neko brings anime discovery tools together in one interface. Visitors can search for titles, explore recommendations and keep a watchlist. The project connects its React and Vite web interface to a Python API built with FastAPI, using AniList for anime data. It also includes an AI chatbot integrated with Conferbot.

It gave me a practical way to explore how a frontend, an API, and an external data source can work together in a small web application.
